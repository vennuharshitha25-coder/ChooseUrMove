🚀 ChooseUrMove – Smart & Safe Navigation App
📌 Overview

SafeRoute is a smart navigation web application designed to help users choose not just the fastest, but the safest and most comfortable route. Unlike traditional navigation systems, it considers real-world factors such as lighting, crowd density, road conditions, and ideal travel time.

❗ Problem Statement

Most navigation apps today focus only on distance and time, ignoring critical safety factors. This can lead users—especially women, students, and daily commuters—to travel through unsafe or uncomfortable routes without awareness.

💡 Solution

SafeRoute provides multiple route options enriched with safety-related data. Users can compare routes based on:

Lighting conditions 🌙
Crowd density 👥
Road condition 🚧
Best time to travel ⏰
Safety score ⭐

This empowers users to make informed and safer travel decisions.

⚙️ Features
🔍 Route Search – Enter source and destination
🛣️ Multiple Route Options – Displays different possible paths
📊 Safety Metrics – Each route includes:
Lighting
Crowd density
Road condition
Travel time
Safety score
🚨 Emergency Button – Quick alert system for emergencies
🤖 AI Assistant (Future Scope) – Smart suggestions and alerts
🧭 App Flow
User signs up and adds emergency contacts
Enters starting point and destination
App displays multiple routes with safety details
User selects preferred route
Navigation begins
Emergency button available anytime
